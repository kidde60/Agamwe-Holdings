# AGAMWE Holdings Company Limited — Corporate Website

Modern responsive corporate website built with **React + TypeScript + Tailwind CSS + Lucide React**.

## Highlights
- Premium responsive corporate design
- AGAMWE branding using supplied logo and profile imagery
- Hero, About, Services, Projects, Insights/visual gallery and Contact sections
- Interactive service capability spotlight
- Selected project experience based on the supplied company profile
- Mobile navigation and smooth scrolling
- Contact form UI ready for backend/email integration

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content source
Company information and selected project experience are based on the supplied AGAMWE Holdings Company Limited profile. Replace or expand content only after confirming against the latest company materials.
